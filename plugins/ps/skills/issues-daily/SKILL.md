# Issues Daily → Today

This skill was renamed and broadened into **`/ps:today`**, which scans open issues *plus* PRs that need you *plus* pending releases — not just issues.

**Invoke the `/ps:today` skill now**, passing along any argument the user gave (e.g. `bug`, `P0`, `mine`). Everything you need lives in that skill's `SKILL.md`. This file exists only so the old `/ps:issues-daily` name keeps working.
